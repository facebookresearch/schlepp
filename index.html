Explore the data

For object interaction, details matter. That is why we provide high-resolution images with dense annotations across cameras.

Downstream tasks

Point tracking

  • ~20K 3D tracks per sequence
  • Visible and in-frustum masks per camera
  • Categorized into body, clothing, carried object, and scene background

Optical flow

  • Forward and backward for every frame
  • Same high-resolution resolution as RGB
  • Depth available for occlusion and validity masks

3D object detection

  • Oriented boxes with category labels
  • Carried objects animated per frame
  • Consistent across all six cameras

Camera pose estimation

  • 3 exocentric and 3 egocentric cameras, synchronized
  • Full intrinsics and extrinsics
  • Metric scale

Monocular depth

  • Metric depth in metres
  • Furnished indoor scenes with multiple people carrying objects
  • Invalid pixels (windows) marked

Human pose and shape

  • MHR parameters per actor and frame
  • Large number of scenes with several actors
  • Realistic occlusions

How it was built

Schlepp was created by distilling motion from video models. The generated videos are set in existing 3D scenes where we replicate and align the motion.

Human-verified sequences

Annotators reviewed every sequence that passed our automatic checks and judged whether the motion and the grasp look plausible. They accepted about 15.9K of 57.2K.

Diverse human actors

Every actor wears physically simulated garments and shows fabric motion under real body dynamics. Skin textures, body shapes, and clothing combinations are drawn from a diverse pool.

Use the dataset

GitHub · facebookresearch/schlepp
from torch.utils.data import DataLoader
from schlepp import SchleppDataset
from schlepp.utils import resize_sample, subsample_tracks

def to_point_tracker(sample):
    sample = resize_sample(sample, short_side=384)
    pt = subsample_tracks(
        sample["point_tracks"], 512, mode="stratified",
    )
    cam = sample["cameras"]["body_follow"]
    return (
        cam["rgb"].permute(0, 2, 3, 1),       # (S, H, W, 3)
        pt["trajs_2d_pix"]["body_follow"],    # (S, 512, 2)
        pt["visible"]["body_follow"],         # (S, 512)
    )

ds = SchleppDataset(
    "/data/schlepp",
    modalities=["rgb", "point_tracks"],
    cameras="body_follow",
    seq_len=24,
    transform=to_point_tracker,
)

loader = DataLoader(ds, batch_size=4, num_workers=8)
for rgbs, trajs, visibs in loader:
    ...   # train your point tracker
