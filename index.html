How it was built

Schlepp was created by distilling motion from video models. The generated videos are set in existing 3D scenes where we replicate and align the motion.

Goal

Goal

The goal

We want to generate a person picking up an object, moving with it inside the room, and placing it down somewhere else. As we want to use arbitrary objects and scenes, we do not want to rely on motion capture data.

Moving an object: grasp, carry, grasp

We query a video model for the two components that make up a carry sequence separately. This makes 2D-3D alignment more feasible, reduces prompt complexity, and limits motion reconstruction errors.

Contact pose

Defining the frame

We place a camera C1 that frames the desired object in an artist-made 3D room, which will stage our motion sequence.

Placing an actor

We add a randomized person in a neutral pose close to the target object. This fixes the person's scale, simplifying the pose and shape recovery.

Conditioning the video model to touch the object

By removing the object, we nudge the model to have the human touch the object and carry it outside the frame, a sequence that naturally includes a grasp.

Generating the grasp motion

The video model completes the sequence, including a grasp frame tg, where the object is about to move. We discard the remaining frames.

Extracting the contact pose

We estimate the body m in the grasp frame and refine it into the contact pose m⋆. We ensure that the person and grasp are in alignment with the 3D world.

Carry motion

Setting up the carry sequence conditioning

To tightly condition the sequence the video model needs to hallucinate, we define an end pose that reuses m⋆, translated by Δ and rotated by ψ (the transformation T). For better framing, we choose a new camera C2.

Conditioning for carry

We render the start and end states from the new camera C2 as the first and last frames for the carry motion sequence.

Generating the carry motion

The video model produces a sequence of frames showing the lift, the walk, and the set-down.

Recovering the carry motion

We extract the pose in every frame, smooth the motion, and "glue" the object to the hands. This eliminates tracking errors and plausibly matches real carrying motion.

Human-verified sequences

Annotators reviewed every sequence that passed our automatic checks and judged whether the motion and the grasp look plausible. They accepted about 15.9K of 57.2K.

Diverse human actors

Every actor wears physically simulated garments and shows fabric motion under real body dynamics. Skin textures, body shapes, and clothing combinations are drawn from a diverse pool.

Use the dataset

GitHub · facebookresearch/schlepp
from torch.utils.data import DataLoader
from schlepp import SchleppDataset
from schlepp.utils import resize_sample, subsample_tracks

def to_point_tracker(sample):
    sample = resize_sample(sample, short_side=384)
    pt = subsample_tracks(
        sample["point_tracks"], 512, mode="stratified",
    )
    cam = sample["cameras"]["body_follow"]
    return (
        cam["rgb"].permute(0, 2, 3, 1),       # (S, H, W, 3)
        pt["trajs_2d_pix"]["body_follow"],    # (S, 512, 2)
        pt["visible"]["body_follow"],         # (S, 512)
    )

ds = SchleppDataset(
    "/data/schlepp",
    modalities=["rgb", "point_tracks"],
    cameras="body_follow",
    seq_len=24,
    transform=to_point_tracker,
)

loader = DataLoader(ds, batch_size=4, num_workers=8)
for rgbs, trajs, visibs in loader:
